# 自由行動とプレイ画面の改善 ExecPlan

## 目的と境界

ユーザーが報告した裏庭への自由行動拒否、待機表示、案内と持ち物操作の回帰、戦闘中の反復警告を直す。現在の`ruined_chapel` v3を遊んでいるCampaignの定義versionは変更せず、既存のCampaign lock、LLM予算、確定前の検証、再送時の冪等性を保つ。報酬の変更（Issue #16）は今回の対象外とする。

`PLANS.md`は現存しないため、既存の`.agent`計画と同じ形式で進捗と検証結果を記録する。作業は現行mainのテストを基点に行い、独立して検証できるまとまりごとにmainへpushする。

## 実装方針

- 裏庭や覗き穴は、既存の主要地点に属する小場所・手掛かりとして提案・保存する。主要Sceneを増やして保存済みCampaignを壊さない。地域外の移動、核心の書き換え、無断のHP・在庫変更は引き続き拒否する。
- 移動・覗き見などの実行要求をMechanicalへ送り、AIの自由行動提案が検証で失敗した場合は、理由と許可された参照を伝えて残予算内で一度だけ再提案する。再提案も失敗した場合は具体的な理由を返し、ダイスや時間を進めない。
- 戦闘開始時のHPリスクは確認し、同じ戦闘の継続Turnでは繰り返さない。敵を倒した後、退室後、結末後に存在しない反撃を警告しない。戦闘以外の結末や不可逆な代償の確認は維持する。
- 判定・描写待ちにはCSS主体のダイス演出を出す。未確定の出目を先に見せず、確定後の出目だけ結果欄で示す。`prefers-reduced-motion`では動きを止める。
- 「遊び方と保存」「プレイの感想」は冒険一覧側へ移し、物語の履歴と入力欄から外す。回復ポーションは該当アイテム行に「使用する」を置き、状態不明・満HP・個数ゼロでは理由付きで無効にする。未対応の装備切替は動くふりをするボタンにしない。
