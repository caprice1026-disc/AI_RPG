## 見つかった問題と修正

1. **判定結果の内部表現が表示される**: `技能判定はsuccess/failure(...)` の既存形式だけを画面上で「成功／失敗」に変換。保存済みデータ、プレイヤー入力、描写本文は変更しない。
2. **結末後も入力を促す**: 完了後の入力欄・送信・回復操作を非表示にし、記録と次の冒険への案内へ置換。描写待ちや復旧の表示は維持。
3. **再開時の表示位置が古い履歴へ戻る**: 初回の履歴取得完了後に最新Turnへ位置を合わせる。過去ページの追加読込ではスクロールを変えない。
4. **CLI統合テストの起動待ちが接続拒否で中断する**: `OSError` ではなくHTTPXの接続・timeout例外を待ち、loopbackのhealth取得にproxy無効・1秒timeoutを設定。アプリの起動方式や待機期限は変更しない。
